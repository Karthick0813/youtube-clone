# YouTube Frontend Clone

A frontend practice project inspired by YouTube, developed to recreate the platform's familiar homepage layout and visual appearance using HTML and CSS.

## Overview

The objective of this project was to gain hands-on experience with frontend development by recreating the look and feel of YouTube's desktop interface. The project focuses on structuring webpage elements, styling components and organizing content into a clean video-browsing layout.

## Features

- YouTube-inspired header with logo, search bar and action icons.
- Navigation sidebar with sections such as Home, Explore, Subscriptions and Library.
- Video thumbnail grid displaying video titles, channel names, view counts and durations.
- Channel profile images and video preview thumbnails.
- CSS-based hover effects and layout styling.
- Grid-based video arrangement using CSS Grid and Flexbox.

## Technology Stack

- **HTML5** – Webpage structure and content.
- **CSS3** – Styling, layouts, positioning and visual design.

## Learning Objectives

- Practising semantic HTML structure.
- Understanding CSS Flexbox and Grid.
- Working with images, icons and local assets.
- Recreating an existing interface through frontend implementation.
- Improving attention to spacing, alignment and visual consistency.


## Project Scope

This is a frontend UI replication project intended for learning purposes. It does not implement YouTube's actual backend, video streaming or account functionality.
